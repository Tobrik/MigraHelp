## Версия 2.1.1 - Исправление ошибок карты

### 🐛 Исправлены критические ошибки

#### Проблема: Tailwind не загружался
- **Ошибка**: `ReferenceError: Can't find variable: tailwind`
- **Причина**: Конфигурация Tailwind вызывалась до загрузки CDN скрипта
- **Решение**: Перемещен `<script src="https://cdn.tailwindcss.com"></script>` ПЕРЕД блоком конфигурации в [index.html](index.html:7-19)

#### Проблема: Несуществующий CSS файл
- **Ошибка**: `Did not parse stylesheet at 'http://localhost:3000/index.css'`
- **Причина**: Ссылка на несуществующий файл index.css
- **Решение**: Удалена строка `<link rel="stylesheet" href="/index.css">` из [index.html](index.html)

#### Проблема: Двойная инициализация карты Leaflet
- **Ошибка**: `Error: Map container is already initialized`
- **Причина**: React.StrictMode в режиме разработки монтирует компоненты дважды
- **Решение**:
  - Убран `React.StrictMode` из [index.tsx](index.tsx:11)
  - Leaflet не поддерживает повторную инициализацию контейнера карты
  - В продакшене это не проблема, но для разработки StrictMode отключен

### ✅ Результат
- Карта Leaflet теперь работает без ошибок
- Все стили Tailwind применяются корректно
- Приложение загружается без ошибок в консоли браузера
