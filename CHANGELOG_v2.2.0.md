## 🆕 Новые компоненты

### 1. Restaurants.tsx
**Расположение:** `components/Restaurants.tsx`

**Функциональность:**
- Отображение списка ресторанов (9 ресторанов в базе)
- Фильтрация по бюджету (экономный, средний, премиум)
- Поиск по названию, кухне, адресу
- Поддержка 5 валют (KZT, USD, RUB, UZS, TJS)
- Отображение контактной информации
- Адаптивный дизайн (grid layout)

**Функции:**
```typescript
- budgetFilter: BudgetFilter - текущий фильтр бюджета
- searchQuery: string - поисковый запрос
- BUDGET_LABELS - названия уровней бюджета
- BUDGET_COLORS - цвета для визуализации
- CURRENCY_NAMES - символы валют
```

### 2. DocumentProcedures.tsx
**Расположение:** `components/DocumentProcedures.tsx`

**Функциональность:**
- Отображение 5 процедур оформления документов
- Расширяемые секции с пошаговыми инструкциями
- Отслеживание прогресса выполнения шагов
- Информация о времени, стоимости, необходимых документах
- Поддержка изменения состояния (выполнено/не выполнено)

**Процедуры:**
- ИИН (Individual ID)
- РВП (Temporary Residence Permit)
- ВНЖ (Permanent Residence)
- Трудовой патент
- Медицинская страховка

## 🚀 Миграция с версии 2.1.1

### Для существующих пользователей

1. **Установите Firebase:**
   ```bash
   npm install firebase
   ```

2. **Создайте `.env.local`:**
   ```bash
   cp .env.example .env.local
   ```

3. **Заполните Firebase конфигурацию:**
   - Получите ключи из Firebase Console
   - Добавьте в `.env.local`

4. **Мигрируйте данные в Firestore:**
   - Экспортируйте данные из `data.ts`
   - Импортируйте в Firestore через Firebase Console

### Breaking Changes

- Удален путь `/phrases` - используйте `/` (главная)
- Изменена структура некоторых типов данных
- Новая система маршрутизации
