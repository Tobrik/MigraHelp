# MigraHelp - Помощник для мигрантов в Казахстане

**MigraHelp** - это веб-приложение, созданное для помощи мигрантам в Казахстане. Приложение предоставляет полную информацию о процедурах оформления документов, полезных местах, ресторанах и поддержку на 5 языках.

## ✨ Основные функции

### 1. 📋 Пошаговые гайды по оформлению документов
- **ИИН (Индивидуальный Идентификационный Номер)**
- **РВП (Разрешение на Временное Проживание)**
- **ВНЖ (Вид на Жительство)**
- **Трудовой патент**
- **Медицинская страховка**

Каждый гайд включает:
- Пошаговые инструкции
- Необходимые документы
- Стоимость и время обработки
- Место обращения
- Отслеживание прогресса

### 2. 🍽️ Поиск ресторанов по бюджету
- Фильтрация по 3 уровням бюджета:
  - **Экономный** (< 5000 ₸)
  - **Средний** (5000-15000 ₸)
  - **Премиум** (> 15000 ₸)
- Поддержка 5 валют:
  - KZT (Казахстанский тенге)
  - USD (Доллар США)
  - RUB (Российский рубль)
  - UZS (Узбекский сўм)
  - TJS (Таджикский сомони)
- Информация о каждом ресторане:
  - Адрес и телефон
  - Тип кухни
  - Среднюю стоимость блюда
  - Веб-сайт

### 3. 🗺️ Интерактивная карта полезных мест
- Более 15 важных мест в Алматы:
  - ЦОНы (Центры обслуживания населения)
  - Учреждения здравоохранения
  - Миграционные службы
  - Центры правовой помощи
- Фильтрация по типам учреждений
- Информация о рабочих часах

### 4. 📄 Управление документами
- Добавление и отслеживание своих документов
- Отслеживание сроков действия
- Цветовая индикация статуса:
  - 🔴 Истёк
  - 🟠 Критический (< 7 дней)
  - 🟡 Предупреждение (< 30 дней)
  - 🟢 В порядке

### 5. 🌍 Поддержка 5 языков
- **Русский** (РУ) - Русский язык
- **Қазақша** (КК) - Казахский язык
- **English** (EN) - Английский язык
- **Ўзбек** (УЗ) - Узбекский язык
- **Тоҷикӣ** (ТЈ) - Таджикский язык

Быстрое переключение языков в панели навигации.

### 6. 🌓 Поддержка тёмной темы
- Автоматическое переключение между светлой и тёмной темой
- Сохранение выбора в localStorage
- Плавные переходы

## 🔧 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/migrahelp.git
cd migrahelp-(ru)
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Создание файла переменных окружения

```bash
cp .env.example .env.local
```

Заполните `VITE_FIREBASE_*` переменные вашими данными из Firebase Console.

### 4. Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

## 📝 Использование

### Добавление документа

1. Перейдите на страницу "Документы"
2. Нажмите кнопку "Добавить документ"
3. Заполните информацию
4. Нажмите "Сохранить"

### Поиск ресторана

1. Перейдите на страницу "Рестораны"
2. Выберите уровень бюджета
3. Используйте поиск для фильтрации
4. Просмотрите информацию о ресторане

### Просмотр процедуры

1. Перейдите на страницу "Процедуры"
2. Выберите нужную процедуру
3. Прочитайте пошаговые инструкции
4. Отмечайте выполненные шаги

### Смена языка

1. Нажмите на выбор языка в панели навигации
2. Выберите нужный язык
3. Интерфейс обновится

## 🌐 Локализация

Приложение поддерживает 5 языков:
- Русский, Казахский, Английский, Узбекский, Таджикский

Для добавления нового языка:
1. Добавьте язык в `types.ts`
2. Добавьте переводы в `data.ts`
3. Добавьте язык в `LanguageSelector.tsx`
